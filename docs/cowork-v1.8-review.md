# Cowork v1.8 integration review

The standalone card contains the FlightList exact-code selection, autocomplete
recovery, both date-range readbacks, explicit eDreams Return selection, TAP
lazy-loaded Economy controls, fresh targeting after reflow and final checklist.

The public card is privacy-sanitized and has no personal profile defaults.
All search settings must be supplied or confirmed for the current request.
The original uploaded card and detailed travel report are not public artifacts.

Validation covers a 1,500–2,600-word body, standalone dependencies, reference
resolution and generated-package parity. Static tests do not prove current
third-party browser behavior. Prior externally reported browser observations
informed these recipes, but were not independently replayed during integration.
Reprice every new search. Research only; no booking or payment.
