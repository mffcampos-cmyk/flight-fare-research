# Flight Fare Research

Use the `flight-fare-research` skill for live airfare or route research.

Use the highest browser engine available (the user's own browser, then a persistent browser-act browser, then a headless tool) and the pacing and challenge rules in its `references/browser-engines.md`. Record every observation with `scripts/run_log.py` and finish with `run_log.py check`. Official APIs are used only when credentials are already configured; this integration ships none. Research only: never book, handle payment or account credentials, or bypass bot controls.
