# Flight Fare Research

Use the `flight-fare-research` skill for live airfare or route research.

Prefer browser-act; if it is not installed, use the host's own browser tool under the same rules. The modular package has no credentialed-API dependency; the supporting skill only routes to official APIs when credentials are already configured. This integration ships none. Follow its evidence, duration, baggage, and no-evasion rules. Do not book flights, handle payment/account credentials, or bypass bot controls.
